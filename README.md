# SugarFit Club

Free community-driven diabetes lifestyle platform.

**Move Together. Control Sugar. Live Better.**

## Features
- Glucose tracking (local, free)
- Post-meal movement logging
- Community challenges
- Educational content
- Progress monitoring
- Mobile-first PWA

Completely free. No login required for core features. Data stored locally in your browser.

## Tech
Next.js + Tailwind CSS + PWA
